یک درگاه و نرم‌افزار مدیریت چند پورتی و تفکیک‌شده محلی فوق‌سریع بر پایه هسته **sing-box 1.13.18**.

ابزاری قدرتمند، کاملاً سمت کاربر و با رعایت کامل حریم خصوصی که به شما امکان می‌دهد $N$ نود پروکسی مجزا (پشتیبانی مستقیم از **VLESS Reality / WS / gRPC**، **Trojan**، **Shadowsocks**، **Hysteria 2** و **WireGuard**) را وارد کرده و دقیقاً $N$ اندپوینت (پورت) محلی مستقل و ایزوله تولید کنید. در این معماری، هر پورت محلی منحصراً به یک نود خروجی و مسیر اختصاصی DNS متصل می‌شود. این ابزار هم به‌صورت **نرم‌افزار دسکتاپ نیتیو (ویندوز، لینوکس، مک)** و هم به‌صورت **وب‌اپلیکیشن بدون نیاز به نصب (Web UI)** در دسترس است.

## 🎯 هدف اصلی و معماری

در سناریوهایی نظیر مدیریت حساب‌های کاربری متعدد، فراخوانی APIهای هوش مصنوعی با اکانت‌های مختلف (مانند **NVIDIA NIM API** یا نمونه‌های متعدد **OpenCode**)، توسعه خزنده‌های وب (Web Scraping)، تست‌های یکپارچه‌سازی و خودکارسازی، برنامه‌ها نیازمند استفاده همزمان از IPهای خروجی متفاوتی هستند.

کلاینت‌های پروکسی سنتی معمولاً فقط یک پورت شنود سراسری ارائه می‌دهند. **General Proxy Manager** یک معماری قطعی، تفکیک‌شده و ۱ به ۱ به‌همراه **پورت مستر هوشمند (Auto-Fastest)** ایجاد می‌کند:

```
[پورت ۲۰۸۰۰: مستر هوشمند سریع‌ترین نود (URLTest)] ───► urltest (انتخاب خودکار کمترین پینگ)
[پورت ۲۰۸۰۱: نود پروکسی شماره ۱] ───► proxy-in-01 ───► proxy-out-01 ───► dns-proxy-01 ───► نود ۱
[پورت ۲۰۸۰۲: نود پروکسی شماره ۲] ───► proxy-in-02 ───► proxy-out-02 ───► dns-proxy-02 ───► نود ۲
[پورت ۲۰۸۰۳: نود پروکسی شماره ۳] ───► proxy-in-03 ───► proxy-out-03 ───► dns-proxy-03 ───► نود ۳
...
[پورت ۲۰۸۰۰ + N]               ───► proxy-in-N  ───► proxy-out-N  ───► dns-proxy-N  ───► نود N
```

> [!IMPORTANT]
> **تفکیک کامل و عدم نشت ترافیک**: هر پورت به عنوان یک درگاه کاملاً مستقل عمل می‌کند. هیچ تداخل مسیریابی بین پورت‌ها وجود ندارد و در صورت قطع ارتباط پروکسی، ترافیک به هیچ‌وجه به صورت مخفیانه به اتصال مستقیم نشت نخواهد کرد (`route.final = "block"`).

## ✨ قابلیت‌های کلیدی (v2.0)

- 🔒 **تفکیک قطعی و ۱ به ۱ پورت‌ها و خروجی‌ها**: هر نود فعال یک پورت محلی اختصاصی با ورودی، خروجی، روت و دی‌ان‌اس تفکیک‌شده دریافت می‌کند.
- ⚡ **پورت مستر سوییچ خودکار (20800)**: پورت تجمیعی یکپارچه برای هدایت خودکار ترافیک به سریع‌ترین نود بر اساس آزمون دوره‌ای `urltest`.
- 🌐 **پشتیبانی مستقیم از ۵ پروتکل اصلی**: پارس مستقیم لینک‌ها و فایل‌های اشتراک Base64 برای:
  - **VLESS** (Reality, WebSocket, gRPC, HTTP, Vision, uTLS)
  - **Trojan** (TLS, SNI, WebSocket)
  - **Shadowsocks** (SIP002 و لینک‌های base64 کلاسیک)
  - **Hysteria 2** (`hy2://` و `hysteria2://`)
  - **WireGuard** (`wg://` و `wireguard://` مطابق با استانداردهای نسخه 1.13.18)
- 🖥️ **کنترلر دسکتاپ هسته سینگ‌باکس**: اجرای مستقیم، توقف و ریستارت باینری سینگ‌باکس از داخل محیط برنامه به‌همراه مشاهده لحظه‌ای لاگ‌ها.
- 🚀 **تنظیم تک‌کلیک پروکسی سیستم در ویندوز**: کلید سریع System Proxy در هدر با اعمال و رفرش آنی تنظیمات شبکه ویندوز (WinINet).
- 📈 **داشبورد زنده سرعت و ترافیک مصرفی**: عقربه و نشانگر سرعت لحظه‌ای دانلود/آپلود، حجم کل و نمودار متحرک امواج ترافیکی با Canvas.
- 🌍 **تشخیص پرچم و نام کشور آیپی خروجی**: نمایش خودکار ایموجی پرچم و کشور (مانند 🇩🇪 Germany یا 🇺🇸 United States) در تست آیپی.
- ⏹️ **دکمه توقف فوری آزمون (Stop Test)**: امکان لغو سریع تست‌های همگانی در حال اجرا.
- 🔄 **سیستم به‌روزرسانی خودکار**: بررسی نسخه‌های جدید از طریق GitHub Releases به‌همراه مشاهده لیست تغییرات.
- 🎨 **تم تیره و روشن مدرن**: طراحی Glassmorphism منطبق بر بالاترین استانداردهای بصری و کنتراست.
- 🌍 **پشتیبانی کامل از ۳ زبان**: انگلیسی، **فارسی (راست‌چین RTL)** و چینی بدون وابستگی به CDN خارجی.
- 🧪 **۳۵ تست واحد و اعتبارسنجی خودکار**: تضمین سلامت و تطابق کامل با `sing-box check`.

## 🚀 راهنمای اجرا

### روش اول: اجرای نسخه نرم‌افزار دسکتاپ (پیشنهادی)

1. فایل نصبی یا پرتابل آماده را از بخش **[GitHub Releases](https://github.com/MahDN/General-Proxy-Manager/releases/latest)** دانلود کنید:
   - **ویندوز**: فایل نصب `.exe` یا `.msi`
   - **لینوکس**: فایل‌های `.AppImage` یا `.deb`
   - **مک**: فایل `.dmg`
2. برنامه را باز کرده، لینک‌های کانفیگ را وارد کنید و در تب سوم دکمه **🟢 Start Sing-Box** را بزنید.

#### بیلد نرم‌افزار دسکتاپ از سورس:
```bash
# نصب پکیج‌ها
npm install

# اجرای محیط توسعه دسکتاپ
npm run dev

# بیلد نهایی فایل باینری
npm run build
```

---

### روش دوم: اجرای نسخه وب (Web UI / مرورگر)

بدون نیاز به نصب هیچ ابزار جانبی، می‌توانید فایل‌های پروژه را با هر وب‌سرور لوکالی اجرا کنید:

```bash
# با پایتون ۳
python -m http.server 8000

# با نودجی‌اس
npx serve .
```
سپس آدرس `http://localhost:8000` را در مرورگر باز کنید.

## 💻 نمونه کدهای استفاده در پروژه‌ها

### ۱. دستور cURL
```bash
# درخواست از پورت نود ۱ با تفکیک دی‌ان‌اس
curl.exe --proxy socks5h://127.0.0.1:20801 https://api.ipify.org?format=json

# درخواست از پورت مستر هوشمند (Auto-Fastest)
curl.exe --proxy http://127.0.0.1:20800 https://api.ipify.org?format=json
```

### ۲. زبان Python
```python
import requests

# کلاینت اول از پورت 20801 (نود ۱) استفاده می‌کند
s1 = requests.Session()
s1.proxies = {"http": "http://127.0.0.1:20801", "https": "http://127.0.0.1:20801"}
print("IP نود ۱:", s1.get("https://api.ipify.org?format=json").json()["ip"])

# کلاینت دوم از پورت مستر هوشمند 20800 استفاده می‌کند
s_master = requests.Session()
s_master.proxies = {"http": "http://127.0.0.1:20800", "https": "http://127.0.0.1:20800"}
print("IP سریع‌ترین نود:", s_master.get("https://api.ipify.org?format=json").json()["ip"])
```
